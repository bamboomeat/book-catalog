GitHub連携設定

進捗の更新をどの端末からでもGitHubに反映するには、書き込み権限を持つ Personal Access Token（Fine-grained、対象リポジトリ: bamboomeat/book-catalog、Repository permissions → Contents: Read and write）が必要です。 トークンはこのブラウザの localStorage にのみ保存され、GitHub 以外には送信されません。閲覧だけなら設定不要です。
